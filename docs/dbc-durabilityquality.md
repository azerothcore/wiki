**The \`DurabilityQuality.dbc\` file**

A client file of 3.3.5a (build 12340). AzerothCore loads it when the server starts. Its rows can be replaced or extended with the [durabilityquality_dbc](durabilityquality_dbc) table of the world database.

**Structure**

| Column | Field | Type   | durabilityquality\_dbc column      | Comment |
| :----: | :---- | :----- | :--------------------------------- | :------ |
| 0      | ID    | uint32 | [ID](durabilityquality_dbc#id)     |         |
| 1      | Data  | float  | [Data](durabilityquality_dbc#data) |         |

The layout of this file is also described on [wowdev.wiki](https://wowdev.wiki/DB/DurabilityQuality).
