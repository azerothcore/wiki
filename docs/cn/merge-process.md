# AzerothCore 合并流程

### PR 合并频率

在 AzerothCore，我们每天只会合并少量 PR，并从 [[To Be Merged]](https://github.com/azerothcore/azerothcore-wotlk/pulls?q=is%3Apr+is%3Aopen+label%3A%22To+Be+Merged%22) 列表中挑选。

每天我们都会挑选最旧的 PR 进行合并，除非出于任何原因有更紧急的 PR 需要优先合并。

如果用户确实需要某个 PR 尽快被合并，可以请求 AC 工作人员给予该 PR 更高的优先级，我们对此相当灵活（例如：某个 hook）。

这个过程可能看起来"很慢"，但这是有原因的：

- 每个人都有机会在 PR 合并到 master 之前对其进行审查，稳定性对我们来说非常重要。

- 测试人员和开发人员仍然有机会在 PR 最终合并之前说"不，各位，先别合并这个！我刚发现这个 PR 存在一个意外的 bug"。

- 我们有非常严格的 PR 接受流程（我们要求至少 1 个代码审查批准和 1 个手动测试员批准），但 bug 总是有可能进入 master 分支。
如果我们一次合并太多 PR，就很难判断究竟是哪一个出了问题。
每天只合并少量 PR 使我们能够快速识别有问题的提交，并尽快修复/回滚它们。
