# 脚本 vs 模块

在 AzerothCore 上，我们并不像其他模拟器那样使用通常意义上的脚本。相反，我们使用模块，因为模块使用起来方便得多。参见 [创建模块](create-a-module)

# 脚本

在切换到模块之前，你仍然想制作一个简单的脚本？请阅读下文。

## 如何学习

如果你从未编写过任何脚本，你可以研究一些[模块的脚本](https://www.azerothcore.org/catalogue/)，进行对比、剖析等……如果你发现一些未解决的问题，修复它们来提升你的技能！

## 如何从零开始创建脚本

你可以使用这个作为基础：https://github.com/azerothcore/azerothcore-boilerplates

## 如何将你的自定义脚本添加到 AzerothCore

为了让你的脚本能够被编译，请阅读**[此处](https://github.com/azerothcore/azerothcore-wotlk/blob/master/src/server/scripts/Custom/README)**的 README。
