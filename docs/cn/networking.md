本指南适用于高级设置，或者只是为了提供更多关于如何为本地或互联网使用设置你的服务器的细节。一般来说，在你的特定操作系统指南中介绍的默认设置对于简单的设置来说已经足够了。

## Worldserver 和 Authserver 配置

对于几乎所有基本设置场景，默认的 localhost (127.0.0.1) IP 设置应该保持不变。默认的 bindip (0.0.0.0) 也应该保持不变。

### 为互联网连接设置认证数据库的 realmlist

在这里，你必须使用你的互联网 IP，这样互联网上的客户端才能找到你的服务器。你必须从你的路由器/防火墙转发或开放端口 3724（authserver）和 8085（worldserver）。使用 TCP 协议。

**Realmlist 表**

你需要确保你的 **authserver** 应用程序将传入的连接指向你的领域（realm）。

- 运行你选择的数据库管理工具（例如 SQLYog 或 HeidiSQL），或使用 MySQL 命令行界面（CLI）。

- 如果你需要从外部机器连接到你的数据库，请阅读 https://www.enovision.net/mysql-ssh-tunnel-heidisql，而不是向 MySQL 服务器开放端口。

- 打开 **acore_auth** 数据库并找到 **realmlist** 表。你需要根据你的需求编辑 **address 字段**：

    - 局域网 IP（192.168.x.x）- 如果你在与运行 WoW 不同的计算机上安装 AzerothCore，但所有涉及的计算机都在同一网络（路由器）上，请使用该计算机的局域网 IP。

    - 127.0.0.1 - 也称为 "localhost"。如果你在与运行 WoW 相同的计算机上安装了 AzerothCore，并且只有你自己连接它，那么请保持此设置以及配置文件中的相关设置不变。

    - 公共 IP 地址 – 如果你想让他人连接到你的服务器，请使用你的外部 IP。访问 http://www.whatismyip.com/ 以查找你的外部 IP 地址。 
        - 如果你在家用网络中托管，很可能需要设置正确的端口转发，这不在本指南的范围内。https://portforward.com 为大多数路由器提供了指南，你的互联网服务提供商也应该能够提供帮助。 
    
    - 完全限定域名 - （mydomain.com 或 warcraft.mydomain.com）与外部 IP 地址类似，如果你想让他人连接到你的服务器，可以使用这个，额外的好处是不必追踪可能变化的动态 IP 地址。 
        - 与公共 IP 地址类似，如果你在家用网络中托管，很可能需要设置端口转发。
        - 此外，你需要配置 DNS 以指向服务器的公共 IP 地址。设置 DNS 不在本指南的范围内，不过你的域名注册商或动态 DNS 提供商应该会有相应的文档。

{% include warning.html content="<b>仅限 Docker：</b>不要更改 localAddress 字段的默认值。" %}

{% include note.html content="如果你使用 HeidiSQL，请确保在编辑值时位于 Data 选项卡中。" %}

 - MySQL CLI 命令（如果你使用了 HeidiSQL 之类的 MySQL 管理器，则不需要此步骤）
    - `$ sudo mysql`
    - 你应该会看到提示符变为 mysql>
    - `use acore_auth`;
    - **将 IP 替换为你在上面选择使用的那个 IP**
    - `UPDATE realmlist SET address = '[your_ip]' WHERE id = 1;`
    - exit
