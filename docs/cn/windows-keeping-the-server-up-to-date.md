## 保持源代码更新

在 GitHub Desktop 中打开你的 AzerothCore 仓库。

1. 点击顶部的 **Fetch origin**，出现后点击 **Pull origin**。

这将把你的本地仓库同步到 azerothcore-wotlk 仓库的最新提交。

1. 现在你需要重新运行 CMake 的 Configure 和 Generate，以更新你的解决方案（.sln）文件。

1. 按照 [Windows 核心安装](windows-core-installation#compiling-the-source) 中的说明编译下载的源代码
