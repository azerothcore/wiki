## 启动服务器

- 在你的构建文件夹中运行 authserver 和 worldserver。

关于如何配置重启器和调试器的详细信息，请访问 [how-to-restart-and-debug](how-to-restart-and-debug) 页面

{% include warning.html content="除非你绝对确定知道自己在做什么以及如何做，否则绝不要直接在你的数据库中创建账号！" %}

- 接下来，直接在 **worldserver** 窗口中输入 GM 命令 **account create** 来创建你的登录账号。语法：（见下面的示例）

- 如果你希望将账号设置为 GM，请在 worldserver 窗口中输入：**account set gmlevel $account #level #realmid**，其中 **$account** 是要更改的账号名，**#level** 可以是 0-4，**#realmid** 是领域 ID。将 **#level** 设置为 "3" 即为 GM 账号级别（数字越大 = 权限越多），而 "-1" 是代表"所有领域"的领域 ID。

{% include tip.html content="打开你的 <b>acore_world</b> 数据库，找到 <b>command</b> 表。这里显示了完整的 GM 命令列表、描述和安全级别。<br/>只要你保持数据库和核心更新，这始终是你所能找到的最新列表。" %}

- 最小化你的服务器并运行 **WoW**（除非你在上面编辑了 realmlist.wtf 的 patchlist 选项，否则永远不要使用 Launcher 运行 WoW）。

- 使用你刚刚创建的用户名/密码登录。

- 应该可以选择 AzerothCore 领域。登录，创建角色，就大功告成了！

## 创建账号

阅读[创建账号](creating-accounts)。

## 设置远程访问
出于开发目的，此步骤并非必需。然而，当你希望他人创建账号时，为了更高的安全性，你应该设置一个注册表单，这样就不必粘贴他们的密码。请查看[远程访问](remote-access)了解如何向服务器发送命令。
