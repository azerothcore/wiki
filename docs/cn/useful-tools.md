# 实用工具

以下是 AzerothCore 开发最实用的工具。

- [Keira3](https://www.azerothcore.org/Keira3/) 是 AzerothCore 的数据库编辑器。点击[此处](https://github.com/azerothcore/keira3#readme)了解更多信息。

- [SpellWork](https://github.com/azerothcore/spellwork) 是一款用于浏览和展示《魔兽世界》法术信息的工具。点击[此处](https://github.com/azerothcore/spellwork#readme)了解更多信息。

- [Unused Guid Search](https://github.com/azerothcore/Unused-Guid-Search) 是一款用于查找数据库中 entry 或 GUID 空缺的工具。点击[此处](https://github.com/azerothcore/Unused-Guid-Search#readme)了解更多信息。

- [AzerothCore Flags Checker](https://www.azerothcore.org/flag-checker/) 是一款基于 Web 的工具，用于查找生物的位掩码中的所有标志。点击[此处](https://github.com/azerothcore/flag-checker#readme)了解更多信息。

- [WoW Database Editor](https://github.com/BAndysc/WoWDatabaseEditor) 是一款用于 Smart Scripts 和数据库编辑的 IDE。点击[此处](https://github.com/BAndysc/WoWDatabaseEditor#readme)了解更多信息。

- [AoWoW](https://github.com/azerothcore/aowow) 是一款适配 AzerothCore 的军械库/数据库查看器。点击[此处](https://github.com/azerothcore/aowow#readme)了解更多信息。

如果你想查找更多工具，请查看 [AzerothCore Catalogue](https://www.azerothcore.org/catalogue.html)。

如果你开发了一款实用工具，并希望它被收录或在目录中展示，请加入 Discord 服务器并联系（ping）任意一位工作人员。
