**从其他开发者那里精选（cherry-pick）的代码：**

请确保原作者已出现在 [AUTHORS](https://github.com/azerothcore/azerothcore-wotlk/blob/master/AUTHORS) 文件中，否则需要将该作者添加进去。如果代码来自其他组织，那么您只需要确保该组织的名称存在即可。
