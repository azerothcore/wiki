# 问题跟踪器标准

[>> 问题跟踪器](https://github.com/azerothcore/azerothcore-wotlk/issues)

**在报告你的问题或事件之前，请务必先搜索是否已存在相关问题。**

**所有报告都是公开的。切勿在报告中留下密码或其他机密信息。**

**切勿将文件上传到问题中！文本请使用 GIST，视频请使用 YouTube！**

### 自我检查清单

- 我使用的是 AzerothCore 的最新版本/修订版吗？在报告之前，我是否需要更新并再次测试？

- 我是否对数据库或核心做了任何可能导致问题的自定义修改？

- 我是否使用了任何可能导致问题的模块？

- 我是否包含了当前使用的 **修订号/hash/提交** 信息？

- 我是否包含了当前使用的数据库**版本**？

- 我是否包含了当前使用的操作系统？

- 我是否包含了复现该问题的步骤？

- 我是否说明了出了什么问题以及预期行为是什么？

- 我是否每个问题只报告一个 bug？
