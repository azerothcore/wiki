# game_event_battleground_holiday

**\`Game_event_battleground_holiday\` 表**

该表用于为战场添加节日，例如用于额外的声望 / 荣誉。

**表结构**

| 字段             | 类型    | 属性     | 键 | 允许为空 | 默认值 | 额外   | 注释                 |
| ---------------- | ------- | -------- | --- | -------- | ------ | ------ | -------------------- |
| [eventEntry][1]  | TINYINT | UNSIGNED | PRI | NO       |        | Unique | 游戏事件的条目       |
| [bgflag][2]      | INT     | UNSIGNED |     | NO       | 0      |        |                      |

[1]: #evententry
[2]: #bgflag

[game_event.eventEntry](game_event#eventEntry)
