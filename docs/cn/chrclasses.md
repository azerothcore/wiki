# ChrClasses.dbc

[`返回:DBC`](dbc-index)

这个 DBC 包含所有可能的玩家职业。

**版本为 3.3.5a**

[如何将 DBC 数据导入我的数据库](how-to-import-dbc-data-in-db)

**表结构**

| 列 | 名称                            | 类型    | 备注                                                                                        |
| ------ | ------------------------------- | ------- | -------------------------------------------------------------------------------------------- |
| 1      | ID                              | Integer |                                                                                              |
| 2      | Unknown                         | Integer | 猎人、潜行者和萨满为 1，死亡骑士为 9，其他职业为 0。在《大灾变》中被移除。 |
| 3      | PowerType                       | Integer | 0 = 法力，1 = 怒气，2 = 集中值，3 = 能量，4 = 快乐值，6 = 符文。2 和 4 未使用。         |

| 5-20   | Name                            | Loc     | 用于显示的名称。                                                                           |
| 21     | NameLangMask                    | Integer | 字符串标志，未使用。                                                                        |
| 22-37  | Name_female                     | Loc     | 如果与基础大小写不同，否则未使用。                                               |
| 38     | NameFemaleLangMask              | Integer | 字符串标志，未使用。                                                                        |
| 39-54  | Name_male                       | Loc     | 如果与基础大小写不同，否则未使用。                                               |

| 57     | [spellClassSet](#spellclassset) | Integer |                                                                                              |

### 字段说明

> 值（Value）

Value 指定了在核心和数据库的多个位置（如 quest_template.RequiresClasses 等）使用的位掩码。

其计算公式为：**Value = 1 << (ID - 1);**
