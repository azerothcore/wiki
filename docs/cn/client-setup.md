AzerothCore 不发布客户端。你需要在互联网上找到你自己的纯净版 3.3.5a 客户端。

- 打开 **WoW\Data** 文件夹中的 realmlist.wtf 文件。realmlist.wtf 文件中的 IP 应与你之前输入到 realmlist 表中的 IP 地址完全相同。

    - 将第一行改为 `set realmlist <realmlist 表中使用的 IP 地址>`
    
    - 示例：set realmlist 127.0.0.1

- （可选）如果你希望使用 WoW Launcher.exe 运行你的客户端，那么你必须将 set patchlist 更改为与你的 realmlist 相同的 IP/DNS 名称。
