# 如何寻求帮助

## 需要帮助吗？

你需要 AzerothCore 方面的支持吗？别担心，我们很乐意帮助你！

无论你是安装 AzerothCore 时遇到困难，还是想询问如何使用或一般性的问题，**我们都会帮助你**。

我们只希望你**以正确的方式**寻求支持。在寻求任何帮助之前，请先阅读本文档。

## FAQ 与常见错误

首先，我们建议你阅读[常见问题](faq)和[常见错误](common-errors)，以找到问题的解决方案。

## 为什么"正确的方式"如此重要？

如果你直接在聊天中提问，问题很容易被淹没，除非恰好当时有在线的人能够帮助你，否则你可能永远得不到帮助。

如果你把问题发到 StackOverflow 上，它就会**一直保留**在那里，任何人都可以在任何时刻帮助你。你也可以在聊天中分享你的问题链接，以增加它的曝光度。你觉得这没道理吗？继续往下读吧。

此外，用户提出的问题大多都是重复的。因此我们需要一种高效的方式来处理所有支持请求。我们使用 StackOverflow 处理支持问题，使用 GitHub 处理 bug 报告。

听起来很复杂？一点也不！**继续往下读**。

## Bug 报告

某个游戏功能（例如法术/任务/天赋等等）没有按预期工作？

恭喜！你刚刚发现了一个 bug，请先搜索[现有的 issue](https://github.com/azerothcore/azerothcore-wotlk/issues)。很有可能已经有人报告了你发现的同一个 bug，在这种情况下，我们恳请你留下评论来"确认"它。

示例：
![AzerothCore 示例 issue 搜索](https://user-images.githubusercontent.com/75517/51130957-9b9f9580-182e-11e9-8f7f-11aa5d7b6d67.png)

如果搜索了现有 issue 报告后，你没有找到任何相关内容，那么你应该[新建一个 issue](https://github.com/azerothcore/azerothcore-wotlk/issues/new)。

## 其他支持请求

- 你在安装 AzerothCore 时遇到错误了吗？
- 文档中是否有你不清楚的地方？
- 你想知道如何用 AzerothCore 实现某个特定功能吗？
- 你是否正在尝试实现新功能、修复 bug 之类的操作？
- 你有关于与 AzerothCore 或其他 AC 自定义模块相关的 C++ 或 SQL 代码的问题吗？

这类问题被视为支持问题，并通过我们的 Discord [支持论坛](https://discord.gg/gkt4y2x)处理。

### 搜索现有问题

你的问题很有可能已经被其他人问过了，所以在发布新帖之前，请先**搜索**一下。

你可以通过搜索关键词或按特定标签排序来实现。

### 如何提出新问题

如果你找不到问题的答案，就应该发布一个新帖。

请记住：

- 添加一个描述性的标题。
  - **糟糕的**示例 `我遇到了数据库错误请帮帮我`。
  - **好的**示例：`导入 SQL 更新后，我遇到了错误 "XXX"`

- 选择一个或多个适合你帖子的标签。

- 在你的帖子中尽可能描述清楚，以帮助他人帮助你。

### 分享你的知识！

如果你遇到了问题并自己解决了，请发布解决方案来帮助其他人！
