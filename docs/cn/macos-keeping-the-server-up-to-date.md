## 保持源代码最新

```sh
cd ~/azerothcore/
git pull origin master
```

```sh
cd build
make -j 8; make install
```

有时我们会向仓库中添加或移除文件。此时有必要重新编译服务器，方式与[首次在 macOS 核心安装中](macos-core-installation#configuring-for-compiling)安装时相同。
