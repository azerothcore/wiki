# DBC Index

The 3.3.5a client (build 12340) has 246 DBC files. Each one has a page with its columns. A page says whether AzerothCore loads the file, and links to the `_dbc` table of the world database that can replace or extend its rows.

A DBC file and its `_dbc` table are not the same thing: the file ships with the client, the table is in the database and only holds the rows a server wants to change. The tables are listed on the [World database page](database-world).

The database tables are documented separately in the [Database Index](database-index).

<ul class="dbc-legend">
<li class="dbc-documented">(Dot) is a page with descriptions of its columns or the content of the file.</li>
<li class="dbc-columns">(Diamond) is a page that only has the names and types of the columns, with links to related files.</li>
</ul>
