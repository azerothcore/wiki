# Archivo

Esta es la lista de páginas del wiki que ya no se mantienen.

Una página acaba aquí cuando está obsoleta o ya no se aplica a AzerothCore, pero conserva suficiente valor histórico o de referencia como para que borrarla fuese una pérdida. No se enlazan desde ningún otro sitio del wiki y todas muestran un aviso de archivado en la parte superior, para que nadie las siga por error.

Las páginas archivadas mantienen la misma url que tenían antes de archivarse, así que los enlaces antiguos desde fuera del wiki siguen funcionando.

Consulta [estándares de la wiki](wiki-standards#paginas-archivadas) para saber cómo archivar una página.
