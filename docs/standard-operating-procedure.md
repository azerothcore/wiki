# Standard Operating Procedure

These pages describe how we work on AzerothCore. Read the ones that match what you are contributing before you open a pull request or an issue.

- [C++ Code Standards](cpp-code-standards): how C++ code in the core and modules should be formatted, named and structured.

- [SQL Standards](sql-standards): how to write SQL queries and name new tables and columns.

- [File Headers](file-headers): the license header every new source file starts with.

- [Issue Tracker Standards](issue-tracker-standards): what to check and include before you report a bug.

- [Wiki Standards](wiki-standards): how wiki pages are named, formatted, linked, translated and archived.
